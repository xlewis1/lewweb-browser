LewWeb — Commands & Controls

Quick-Reference Manual v1.0.0

A deliberately minimal, keyboard-driven browser experiment

Overview

LewWeb is a CLI + keyboard-driven experimental browser built with C++, Qt6, QtWebEngine, and Chromium. It deliberately rejects conventional browser UI. There is no toolbar, no address bar, no visible tab strip. All interaction is keyboard-driven or command-based.

Commands

Basic

Launch LewWeb

lewweb

Show help

lewweb --help

Show extended Qt options

lewweb --help-all

Show version

lewweb --version

Suppress startup logging

lewweb --quiet

Opening and Searching

Open LewWeb home page

lewweb --home

Open a URL

lewweb --open https://example.com

Search DuckDuckGo (default)

lewweb --search "query"

Search with provider

Use one of the following flags with --search:
--wikipedia Wikipedia
--github GitHub
--youtube YouTube
--reddit Reddit
--google Google
--images Image search
--news News search
lewweb --search "Jupiter" --wikipedia

Navigation

lewweb --back

Go back

lewweb --forward

Go forward

lewweb --reload

Reload current page

lewweb --stop

Stop loading

Tabs

LewWeb deliberately hides the tab strip. Tabs still exist internally and are fully controlled via commands and keyboard shortcuts.

lewweb --new-tab

Create new tab

lewweb --close-tab

Close current tab

lewweb --tab N

Switch to tab N (1-indexed)

lewweb --next-tab

Switch to next tab

lewweb --previous-tab

Switch to previous tab

lewweb --list-tabs

List all open tabs

Bookmarks

Bookmarks are persistent and stored locally. Names can contain spaces.

lewweb --new-bookmark "name" https://example.com

Create named bookmark

lewweb --save-bookmark "name"

Save current page under name

lewweb --open-bookmark "name"

Open saved bookmark

lewweb --delete-bookmark "name"

Delete bookmark

Zoom and Display

lewweb --zoom-in

Increase zoom level

lewweb --zoom-out

Decrease zoom level

lewweb --zoom 150

Set zoom to percentage (e.g., 150 = 150%)

lewweb --fullscreen

Toggle fullscreen mode

Browser Window Controls

There is no conventional address bar or toolbar. The browser window is entirely keyboard-driven. Press o to access the in-window command interface.

Command Interface

Open command interface

o

The command interface accepts the same command vocabulary as the CLI. You can issue commands without leaving LewWeb.

o
--search "Jupiter" --wikipedia
Enter

Page Movement (Vim-style)

Note: LewWeb intentionally uses j for up and k for down. This is deliberate and differs from conventional Vim bindings.

Key Action
h Scroll left
l Scroll right
j Scroll up
k Scroll down

Keyboard Shortcuts

Tabs
Cmd/Ctrl + T New tab
Cmd/Ctrl + W Close tab
Cmd/Ctrl + Tab Next tab
Cmd/Ctrl + Shift + Tab Previous tab
Navigation
Alt + ← Back
Alt + → Forward
Cmd/Ctrl + R Reload
Display
F11 Toggle fullscreen
+ Zoom in
− Zoom out
Browser Controls
o Open command interface
Esc Stop loading / exit fullscreen
